Grove 0.3.2 removes repository deletion.

- Grove can no longer delete a GitHub repository. Delete Repository is gone from the context menu and the Manage tab, and Ask Grove no longer suggests deleting.
- Grove never sends a delete request to GitHub, even if asked. To delete a repository, use its Settings page on github.com, where GitHub asks you to confirm your identity.
- Rename, Edit Description, Archive, and Transfer work as before, each behind a review.

Install from inside Grove with Grove > Check for Updates…, or download the ZIP, unzip Grove.app, and move it to Applications. The app is Developer ID signed and notarized.

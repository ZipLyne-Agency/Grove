Grove 0.3.1 simplifies the menu bar list.

- Quick Access now shows repository names only, in the sort order you choose.
- Pinned repositories and services no longer appear in Quick Access. They stay pinned in the Grove window.
- Copy Link, Open on GitHub, and Ask Grove still appear when you hover over a repository or select it with the arrow keys.

Install from inside Grove with Grove > Check for Updates…, or download the ZIP, unzip Grove.app, and move it to Applications. The app is Developer ID signed and notarized.
